# 捞一条 · 网页版（PWA）

把收藏里没看的，按你的节奏一条条捞出来。

纯静态：没有编译、没有框架、没有后端。`index.html` + `styles.css` + `app.js` + `sw.js`，扔到任何能开 HTTPS 的静态托管上就能用。

## 一、三分钟上线

PWA（加到主屏幕、通知）必须走 **HTTPS**，本地双击 index.html 是不行的。最省事的两种：

**方法 A：Netlify Drop（拖一下）**
1. 打开 <https://app.netlify.com/drop>
2. 把整个 `laoyitiao` 文件夹拖进去
3. 几秒后给你一个 `https://xxx.netlify.app` 的链接，手机打开就是了
4. 以后改了文件，再拖一次就更新

**方法 B：GitHub Pages**
1. 新建一个仓库，把这些文件推上去
2. Settings → Pages → Source 选 main 分支根目录
3. 地址是 `https://你的用户名.github.io/仓库名/`

**本地预览**（不能测通知，但能看页面）
```
cd laoyitiao
python3 -m http.server 8080
# 手机和电脑同一 WiFi 时：http://电脑的IP:8080
```

## 二、手机上怎么装

- **iPhone**：Safari 打开链接 → 底部「分享」→「添加到主屏幕」→ 从主屏幕图标打开 → 引导最后一步点「打开通知」。
  浏览器里直接开的网页收不到通知，这是苹果的规定，引导页里有说。
- **安卓（Chrome / Edge / 华为浏览器）**：打开链接会弹「安装」，或者菜单里「添加到主屏幕」。装好后抖音的分享面板里会出现「捞一条」，直接分享过来，不用复制。

## 三、现在能做什么、不能做什么

能：
- 存（粘贴链接 / 分享文字，自动识别抖音、小红书、B 站、快手；识别不出来自己写名字；重复的会提示）
- 排队 10 条 + 候补无限；排队中 7 天没看退到候补末尾，不删
- 按作息推：每个场景自己设几天、几点、最多几条、适合看多长的；可以加自定义场景
- 今天页：一次只给一条，按"标签 → 随时 → 时长合适 → 剩余天数少"挑；看完接下一条；按剩余时间挑
- 通知上三个动作：现在看 / 现在不方便 / 不看了；"不方便"会让那个时段以后少推
- 队伍页左滑「不看了」；点一行可以改；候补可以插队
- 看过的永久留着；不看的留 30 天可找回
- 数据导出 / 导入（JSON）

暂时不能（第二步）：
- **App 关掉之后的推送**。现在的通知是"本地版"：页面开着、或者在后台没被系统杀掉时，时段一开始会推一条。真正的离线推送要一个小服务端（见下）。
- 自动抓封面和标题。抖音、小红书有反爬，浏览器里也跨不了域，得在服务端做。

## 四、第二步：离线推送（约一天工作量）

思路很简单，全部免费额度够用：

1. 静态页面放 **Cloudflare Pages**
2. 一个 **Cloudflare Worker**：
   - `POST /subscribe`：手机把推送订阅（`PushSubscription`）和作息、队伍摘要传上来，存进 KV
   - **Cron Trigger 每 5 分钟**跑一次：对每个用户算"现在是不是某个时段刚开始"，是就按同一套挑选规则挑一条，用 `web-push`（VAPID）推出去
3. `sw.js` 里已经写好了 `push` 事件和三个动作按钮，服务端推的 payload 和本地版一样：`{ title, body, itemId, url, sceneId, tag }`
4. 用户没有账号，用一个随机的设备 ID 认人（`app.js` 里加一行生成并存起来即可）

要注意的国内特殊情况：安卓上谷歌的推送通道在国内不通，Web Push 在国内安卓浏览器上能不能到，取决于用的是哪家浏览器（Chrome 系不行，部分国产浏览器可以）。iOS 16.4+ 的 Web Push 走苹果通道，国内没问题。

## 五、文件

```
index.html            页面骨架 + 底栏
styles.css            样式（颜色和 Figma 稿一致）
app.js                所有逻辑：数据、规则、页面
sw.js                 离线缓存 + 通知
manifest.webmanifest  PWA 清单（含安卓分享目标）
icons/                app 图标（由 tools/make-icons.js 从 SVG 生成）
tools/make-icons.js   生成图标
tools/screenshot.js   用 Chromium 跑一遍所有页面截图 + 规则自检
```

## 六、常用改动在哪

- 排队条数、轮换天数、不看的保留天数：`app.js` 最上面三个常量
- 默认三个场景：`DEFAULT_SCENES`
- 挑选规则：`pickForPush` / `pickForToday`
- 提醒文案：`reminderText`
- 颜色：`styles.css` 最上面的 `:root`
